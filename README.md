# 📄 AI Powered PDF Chatbot (Real RAG)

An AI-powered PDF Question Answering system built using:

- 🧠 Embedding-based Retrieval (Sentence Transformers)
- ⚡ FAISS Vector Search
- 🤖 Groq LLM (LLaMA 3.1)
- 🌐 Streamlit Web Interface

## 🚀 Features

- Upload any PDF
- Ask questions about the document
- Uses real Retrieval-Augmented Generation (RAG)
- Embedding-based similarity search
- Clean Streamlit UI

## 🛠️ Tech Stack

- Python
- Streamlit
- Sentence-Transformers
- FAISS
- Groq API
- PyPDF

pip install -r requirements.txt
